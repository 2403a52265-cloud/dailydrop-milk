Design Patterns Used

1. Singleton: Provides one shared configuration object for the application.

2. Factory: Creates a delivery option based on the customer's selection.

3. Observer: Could notify customers when milk is back in stock or an order status changes.

4. Strategy: Could calculate delivery fees using standard, express, or free-delivery rules.

5. Command: Could represent actions such as adding products, placing orders, or cancelling orders as objects.

Observer, Strategy, and Command are extension ideas here; they are not implemented as complete design patterns in this demo.
